休息区：两组联合条件都没有补全任何对象。复用的旧 Observer 有 45 框，其中仅 35 进入官方 context，10 个被词表桥接遗漏；原输入包括 armchair4 + chair4 + seating4、tv + tv_monitor、furniture8 等重叠查询来源。GT visible/full 为 27/63。数量差不是严格检测准确率，但旧观察有明显的重复风险。不能把立即 END 直接归因于某一个因素，也不能用 max-new-objects 增大修复已经主动 END 的输出。text_only seed1 只有 lighting2、plant1、cushion1，遗漏描述明确提到的椅子和电视；seed2 出现 bed2。

客厅：GT visible/full 为 7/22，旧 Observer 只有 sofa 和 table。详细描述组新增数量 5/3/3，比短句组 4/9/3 更集中，但几何仍不可靠。详细描述 seed0 的 desk 高度只有约 0.31 米，底部在假设场景地面上方约 0.155 米；tv_stand 高约 0.23 米。text_only seed2 出现 2 张床、17 个 nature_shelf_trinkets、4 个 book_stack、2 个 book_column，且没有 sofa，不能视为对输入客厅的可靠复原。

浴室：GT visible/full 为 10/29，Observer7。纯文本前两个 seed 有 sink、mirror、toilet，语义相对接近浴室，但数量和布局仍未配准。详细描述 seed0 追加 27 个对象，其中 6 个 wineglass、4 个 cup、2 个 food_bag、2 个 book_stack、6 个 nature_shelf_trinkets 等；它体现杂物生成偏移，不能因对象更多就称补全更好。seed1 又只追加2个，跨 seed 波动明显。

Qwen 描述整体抓到了房间语义，但并非逐句准确：休息区写电视放在玻璃柜上，而原图更像电视挂在柜子上方墙面。这种关系误差会成为生成条件。颜色、装饰风格和天花板材质也未必能通过当前对象类别/几何 Encoder 表达。

## 程序、几何与参考指标

18 份联合 G_full 的原观测对象逐字段保持不变，均通过 tensorize(max_objects=160)。生成/合并流程成立，不等于结构正确。

同类别 AABB IoU>=0.25 对 GT hidden 做一对一匹配：boxes_room 34 个新增对象中 0 匹配，boxes_caption 46 个中 0 匹配。两个组各自的 GT hidden 总数均为 210（3 个场景分别 36、15、19，对每个 seed 重复计算）。同类别数量交集分别为21和19，仅为无几何类别重叠，不是准确率。单张输入的隐藏世界有多解，GT匹配不是合理性的唯一判据；当前 Observer/坐标/尺寸错误也会压低这些指标。

当前 full 约定下，16 个生成柜子/桌子/电视柜等对象的底部相对假设场景地面 y=0 的绝对偏差中位数为 0.162426 米。同一原始尺寸按 half 解释，偏差中位数为 0.003547 米。这是尺寸含义错误的强线索，但不是物理地面标定，也不是已经重跑 half 条件的结果。若确定采用 half，必须同时修改输入尺寸归一化前的除2和输出解码后的乘2，不能只把最终输出放大。

上一轮默认 full 只对应 demo 将 size 传入 dimensions 的路径，并不足以证明 checkpoint 的实际训练尺寸语义。此处需要先查训练数据/原始盒子约定，避免再次把未核实的桥接当作可靠前提。

## 下一步：保持不训练

1. 先用官方有已知几何的场景或训练数据样例核实尺寸与坐标转换，做数据 round-trip；若暂时没有可核验的训练样例，将 full/half 作为两个预先固定的桥接假设报告，不按图选择。
2. 使用统一的可见实例清单消除同一实例被多个类别重复查询；保留官方细类名称供 M3D 输入，另映射 mpcat40 供 Adapter 输出。最新 canonical 类别去重只能合并别名，不能解决 chair/seating/furniture 之间所有实例重复，而且本轮复用的是旧输出。
3. 在相同桥接和短描述下，做 GT-observed 与 Qwen-observed 的成对推理诊断，隔离 Observer 误差。GT 只用于诊断，不成为最终系统输入；共同桥接仍错误时，两者都差不能证明 Observer 无用。
4. 桥接固定后，比较房间类型短句与简短结构描述。描述只强调房间用途、主要可见家具和可靠关系；不靠长篇颜色装饰描述或禁止某个具体错误物体调优。文本带来的变化不等于改善。
5. 用预先固定的新验证样本集检查迁移，保持原 split；例如每栋抽3张且固定 seed。旧三图保留为调试集，不能作为广泛有效性的证据。此时仍不把纯文本布局直接拼入 G_obs。

如果固定接口、较可靠观测和简短描述后仍反复出现提前 END、生成偏移或位置错误，应接受官方权重对该任务的免训练迁移能力有限；继续堆叠逐图规则无法补上训练分布差异。
