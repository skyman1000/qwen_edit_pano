# 四组对照后的原因归纳（2026-10-11）

同一客厅、同一观测文件、seed0。

|size|text|新增|主要现象|
|---|---|---:|---|
|full|房间类型|4|落地家具尺寸偏小，多个底部高于假定地面|
|full|空|5|同类问题仍存在|
|half|房间类型|3|镜子、书桌、椅子；书桌高度0.689米、底部0.0009米|
|half|空|5|镜子、电视柜、厨房柜、罐、花盆；花盆底部0.0125米，但部分柜体仍离假定地面约0.12米|

## 已查实的执行事实

四份config除text和size_convention之外一致。通过raw_normalized中的context反归一化确认：half输入size恰为full的0.5，中心不变；四组原观测对象与G_obs逐字段一致；均通过现有tensorize(max_objects160)；都输出END，无截断。不是参数未生效、padding容量或导出丢失的问题。weight/source路径相同不等于有完整历史文件哈希，不能声称已验证整个环境的位级一致性。

## 1. 尺寸接口：half得到强支持，但尚非全部训练数据溯源证明

上轮多个落地类别的scene center_y≈decoded size_y，而当前full输出将size_y当完整高，使底部约为半个中心高度。这轮成对修正context/输出后，生成桌高0.689米，底部约0.001米，花盆底部约0.013米，支持当前权重的sizes应按半边长适配。

新旧轨迹不是同一对象逐项对照，不能把布局差异全部量化归因于尺寸变化；仍有chair底部0.152米、柜体约0.12米，不应把half说成彻底解决几何。模型多数据源/支撑面/相机与地面放置等均待核对。默认full最初来自不完整的官方预处理溯源，应承认其证据不足。当前建议后续诊断固定half，并保留full记录；不自动覆盖历史结果或把所有旧坐标缩放。

## 2. Observer几何错误独立存在

沙发预测中心z3.73米，现有GT约2.578米；桌子1.72米，GT约0.951米。这次half仅改变M3D内部size单位与生成导出，不修正预测center，最终G_full保留原观测错误。这既是保留输入的设计结果，也是必须先改善Observer的原因。

## 3. 可见区域冲突：不是只缺“更多隐藏对象”

half+text镜子中心local[-0.261,-0.024,4.716]，half+notext约[-0.316,-0.051,5.018]。使用图像90度水平视场角、768方图，预测框投影分别约[333,353,393,419]和[336,358,384,418]，落在原图沙发上方可见空白墙面。

这是当前几何解释下与输入图像不一致的具体证据，不能把这些新对象统称为hidden。中心/深度本身也可能有误，因此并非独立精确重建真值。但对目标“保持局部图一致的全景生成”已经是重要问题。

M3D当前输入只有对象类别/几何、全1 room mask及可选短文本；没有图像、相机视锥/可见掩码、深度遮挡和已知空区域。Observed存在信息不能表达所有可见区域不存在某对象的证据。不能只按z<0过滤新对象：侧面和前方遮挡也可能属于未观测区域。预测未知空间时需要相机可见性条件或依据图像的后验一致性筛选，先诊断再选择最小实现。

证据图片：outputs/completion_indoor_val3_analysis/completion_indoor_half{text,notext}_run001_mirror_projection.jpg。

## 4. 训练条件分布不匹配

官方排序前缀训练与任意相机可见集合不同，这是源码事实，但单seed实验不能量化其独立贡献。给同一集合重新排序不能补足缺失元素，当前非PE模型也没有对象序号编码。官方预训练本来是布局生成/续写，不能把API可接收框等同于已经解决360隐藏世界补全。

## 5. 文本不是已证实根因

text和notext在half下均生成与可见墙面矛盾的镜子；因此关闭文本并没有消除核心问题。文本会改变生成分布，但无证据应永久关闭BERT。继续保持text_condition true作为网络配置，是否用房间句可保留对照。

## 有明确目的的下一步

- 停止继续切换text或单纯扩大seed来定位接口错误；固定half+房间类型作工作基线，保留旧对照。
- 改Observer为实例级定位，增加3D回投影，保留现有Adapter字段。2D定位解决对应与去重，不保证米制几何；必要时单独改善深度来源。
- 做同一场景GT observed的补全诊断，正确桥接原始OBB/房间坐标，比较原先预测输入。GT只作诊断，不进入最终单图推理。
- 若GT可见集也补不好，再比较同场景官方排序前缀，隔离“布局框/归一化问题”和“可见集合分布问题”。注意本项目ERP full状态可能跨房间，官方单room布局的范围也需对齐。
- 几何接口稳定后，用 observed+hidden训练采样适配completion，并考虑相机可见性条件/投影一致性筛选，防止往已知空区域添物。不要直接强制全部生成到相机后方。
- 当前Oracle训练继续独立；先验证GT结构对生图有用，再投入大规模上游训练。没有证据要求改Adapter输入字段或解冻生成器。

本轮只读检查、CPU诊断和可视化，没有修改默认推理行为或启动GPU。不能用一个场景一个seed声称唯一根因已证明或half带来总体质量提升。
