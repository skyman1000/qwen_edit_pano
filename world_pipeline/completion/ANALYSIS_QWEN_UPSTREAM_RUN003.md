# Qwen upstream run003 结果分析

2026-10-12。读取 run001/002/003 状态、run003 全部72份补全原文、请求和状态图，重新计算 Observer 匹配，并查看12图的原图/2D框/3D投影联系图。仅CPU分析，没有新模型推理，没有改写历史输出或正在训练的Adapter。

## 核心结论

流程完成率提高，但没有建立可靠三维观察和隐藏世界补全。188个数值有效3D框中74个完整复制提示词示例，约39.4%。72次补全均明确返回空列表，且保存的G_full对象逐项等于G_obs。这不是解析漏掉新增对象，也不是容量耗尽。当前不能将该结果作为完整预测世界接入Adapter后的效果证据。

## 运行和观察指标

- run001：5 completed / 7 failed；run002：8 completed / 4 failed；run003：9 completed / 3 partial。
- run003共189个预测可见实例，188个几何字段数值有效；对应GT可见实例150个。
- 同类别2D IoU>=0.25、一对一匹配：54对；参考precision 28.6%，recall 36.0%。匹配后中心误差均值1.608m，尺寸各轴绝对误差均值0.389m。
- 同类别3D AABB IoU>=0.25仅3对。不能把这3对的中心均值0.499m当整体几何精度。
- 去掉示例复制者后，2D匹配对象剩37对，中心误差均值1.374m、中位1.183m。去除示例污染也不能直接证明其余几何可靠；不建议把这些对象静默删掉后报“修复成功”。
- 7张图的12个类别查询达到8实例上限。这个现象需要结合图像复查，不能断言所有达到上限者都是幻觉，也不能把上限当真实物体数。

## 三维数值示例污染

74个不同对象输出完全相同的9个数：

`[0.2,0.1,2.5,0.6,0.9,0.5,0,0,0]`

这正是其保存请求中的数字示例。所有74份请求都包含该示例，分布在多张图和类别。转换后的中心统一为Local `[0.2,-0.1,2.5]`，大小统一为`[0.6,0.9,0.5]`，导致投影堆在相同区域。前一版本为解决JSON问题加入具体几何答案示例，造成了输出内容污染；程序只验证数值格式没有识别其预测意义。

下一步应移除3D答案数值示例，不再提高token或把示例答案替换成另一组数。先固定已有2D框，只重新测试少量3D查询。若输出仍有米级误差，再决定是否需要专用单目几何估计；不能只靠JSON正确宣布Observer完成。

## 二维观察与评价边界

可视化可见部分床/沙发/栏杆得到对应框，但厨房、庭院及灯具/小物体出现密集框；类似走廊有的图只保留一个实例，类别枚举也会漏检。因此不能仅优化三维转换。

GT是当前经过筛选的世界对象集合，不是对所有图像像素物体的穷尽标注。朝庭院的样本GT只有2个可见对象，而模型输出40个；这不意味着38个全部是假物体，可能同时包含标注范围差异、拆分粒度差异和错误检测。评估数值应称相对当前GT的参考匹配，结合人工检查，而不是无条件当通用检测准确率。

当前原图中包含室内朝户外的视野。根据相机所属室内region筛选不保证Local全部呈现室内。保留原清单与分组，不能因结果差而换验证图片。

## Completion 实际没有发生

GT-observed条件36/36、predicted-observed条件36/36均返回`hidden_objects=[]`。12场景的GT隐藏对象合计313个；按3个seed重复统计为939，不能称939个独立对象。

每个请求capacity=64，三组seed均存在；raw响应本身就是空列表，不是导出/解析过滤造成。观测保持由拼接程序保证，空补全时更是恒等操作，不能作为模型能力成绩。空候选间相似度为1也不是好的一致性。

现有提示允许空结果，并混合强烈的“不要新增可见冲突、不要重复、不要推断远处”等限制。模型可能采取保守空答案，这是基于提示与输出的解释，未由消融确认；不能由此证明Qwen不能想象隐藏世界，也不能宣称只改一句就能解决。

下一步将Observer的事实提取与Completion的假设生成在指令上明确分开。先在固定GT G_obs条件下只测试语义提议（潜在类别、与已知物体关系、理由、明确为假设），不要求同时输出3D数值。该阶段有非平凡合理提议之后，再定位这些提议。保持允许真正空候选，不强迫每张图生成固定数量作为“成功”标准。

## 下一步优先级

1. 固定这份run003记录，不重复同协议72次补全，也不接ERP判断补全好坏。
2. 去除3D数值示例，以已有2D框为条件做小规模几何重测；配套GT 2D框诊断能区分定位与三维估计误差，GT仅用于诊断。
3. 固定GT G_obs进行少量语义隐藏提议诊断，移除“事实观察”的约束混淆，先检验是否能生成合理假设。不要用真实hidden GT写提示或指定应生成的对象。
4. 根据上述结果决定继续Qwen几何路线还是采用专用几何组件。M3DLayout保持既有布局先验/对照角色，其任意可见集合适配问题并未因此解决，不直接串回来。
5. 新Adapter训练独立继续；预测世界仍保留现有category/center/AABB/validity/mask接口。

本报告提出后续修改方向，不代表新的推理入口或改进效果已经实现。当前研究的进展是定位到输入协议污染与空补全行为，不能写作完成了高质量世界恢复。
